# Benchmark status

An earlier four-model benchmark was intentionally stopped at the user's request. That partial
run has been superseded by the completed benchmark in this directory.

The completed run used the real capsule dataset, seed 42, batch size 64, a 100-epoch ceiling,
ReduceLROnPlateau, and patience-10 early stopping. See `benchmark.json` and each model's
evidence directory for the final auditable results.
